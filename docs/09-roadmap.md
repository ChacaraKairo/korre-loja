# Roadmap — KORRE Loja

## Fase 0 — Documentação e planejamento

Objetivo: definir o produto antes de codar.

Entregáveis:

- documentação geral;
- arquitetura;
- modelo de banco;
- regras de afiliado;
- roadmap;
- checklist;
- inventário de imagens.

## Fase 1 — MVP técnico

Objetivo: ter site, backend e admin funcionando localmente.

Entregáveis:

- monorepo criado;
- backend NestJS;
- PostgreSQL + Prisma;
- auth admin;
- CRUD de categorias;
- CRUD de produtos;
- CRUD de links afiliados;
- site listando produtos;
- registro de cliques;
- admin desktop básico;
- README de execução.

## Fase 2 — MVP público

Objetivo: publicar vitrine inicial.

Entregáveis:

- deploy do site;
- deploy do backend;
- banco gerenciado;
- domínio/subdomínio;
- política de privacidade;
- aviso de afiliado;
- produtos cadastrados manualmente;
- dashboard de cliques;
- logs básicos.

## Fase 3 — Operação e métricas

Objetivo: entender o comportamento dos visitantes.

Entregáveis:

- relatórios por período;
- top produtos;
- top categorias;
- campanhas;
- produtos sem clique;
- exportação CSV;
- busca no admin;
- filtros avançados.

## Fase 4 — Integração com ecossistema KORRE

Objetivo: conectar loja ao público do app KORRE.

Entregáveis:

- banner no site principal;
- links no app KORRE;
- categorias recomendadas por perfil;
- campanhas por módulo do app;
- produtos recomendados para garagem, oficina, combustível e rotina.

## Fase 5 — Automação futura

Objetivo: reduzir trabalho manual com segurança.

Possíveis entregáveis:

- validação de links;
- atualização assistida de preço de referência;
- importação controlada de produtos;
- integração com APIs oficiais disponíveis;
- verificação de produtos inativos;
- alertas no admin.

## Fora de escopo inicial

- checkout próprio;
- pagamento dentro da KORRE Loja;
- estoque;
- emissão de nota;
- logística;
- atendimento de pedido;
- scraping de páginas;
- marketplace multi-vendedor;
- app mobile da loja no MVP.
