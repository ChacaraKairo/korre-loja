# Arquitetura de categorias — Loja do Korre

## Objetivo

A Loja do Korre deve organizar produtos pela rotina real de quem trabalha com veículo, e não apenas por departamentos tradicionais. A navegação precisa ajudar o usuário a responder rapidamente:

- qual produto resolve meu problema hoje?
- qual item reduz custo, aumenta segurança ou melhora conforto?
- qual kit faz sentido para meu tipo de trabalho?
- o que serve para carro, moto, bicicleta, scooter elétrica ou outros veículos?

## Princípio de navegação

A estrutura oficial combina quatro formas de descoberta:

1. **Por departamento**: eletrônicos, autopeças, vestimentas, ferramentas etc.
2. **Por tipo de veículo**: carro, moto, bicicleta, scooter elétrica e outros.
3. **Por profissão/rotina**: motorista de aplicativo, taxista, motoboy, entregador, ciclista profissional.
4. **Por problema/objetivo**: economia, segurança, conforto, chuva, noite, organização, manutenção e emergência.
